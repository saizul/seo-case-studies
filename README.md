# SEO and Performance Case Studies

Short, factual write-ups of real work by [Saizul Amin](https://saizul.com), a web developer, SEO and automation specialist based in Bangladesh. Each case study states the problem, how it was diagnosed, what was changed and what was measured. Only numbers that were actually measured are published.

## Format

Every case study follows the same structure:

1. Context
2. Problem
3. Diagnosis method
4. Actions
5. Results
6. What is next
7. Lessons
